# Security Policy

## Supported versions

The project is in early development. Security updates currently target the latest code on `main`.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature when it is available for this repository. Include:

- A clear description of the issue
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested mitigation

Allow reasonable time for investigation before public disclosure.

## Sensitive data

This repository must not contain credentials, access tokens, identifiable patient records, protected health information, or confidential DHIS2 exports. Immediately revoke any exposed credential and report the exposure privately.
